# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in **LogSentinel** (for example, a parser ReDoS, path traversal in report output, or HTML escaping bypass in the HTML reporter), please report it responsibly:

1. **Do not** open a public GitHub issue with exploit details.
2. Open a [GitHub Security Advisory](https://github.com/faizi-cybsec/LogSentinel/security/advisories/new) or contact the maintainer via GitHub (`@faizi-cybsec`).
3. Include a clear description, reproduction steps, and potential impact.

We aim to acknowledge reports within 48 hours and release a fix as quickly as possible.
